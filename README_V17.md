# INDEBOX V17 — 코드 가독성 정리

V16 프로젝트의 `src` 폴더에 압축 파일의 `src` 폴더를 덮어쓰세요.

- 페이지 및 컴포넌트의 TS/TSX 코드를 재정렬했습니다.
- 중첩 JSX를 여러 줄로 분리하고 들여쓰기를 정리했습니다.
- TypeScript AST 기반으로 처리했으며 0개의 파싱 오류를 확인했습니다.
- `src/styles`의 SCSS/CSS는 V16 상태를 유지했습니다.
- 이미지와 프로젝트 설정 파일은 변경하지 않았습니다.

주의: 실제 Vite 빌드 및 브라우저 테스트는 수행하지 않았습니다.
