# INDEBOX V16 — 코드 정리 및 서브메뉴 높이 조정

V15까지 적용된 프로젝트를 기준으로 `src` 내부의 코드 파일을 읽기 쉽도록 재정렬했습니다.

## 적용
ZIP의 `src` 폴더를 기존 프로젝트에 덮어쓰세요.
이미지(`public/images`), 패키지 설정, 기타 정적 파일은 포함하지 않았으며 변경하지 않았습니다.

## 디자인 수정
- PC 드롭다운의 강제 최소 높이 제거
- 드롭다운 상하 패딩 축소
- 전체보기와 서브메뉴 사이 간격 축소
- 서브메뉴 버튼 간격 축소
- 모바일 드롭다운 간격 축소

## 코드 정리
- TS/TSX의 import, 타입, 선언과 일반 구문 줄바꿈 및 들여쓰기 정리
- CSS/SCSS의 선택자, 선언, 미디어 쿼리 블록 줄바꿈 및 들여쓰기 정리
- 기존 React 컴포넌트, 페이지, 데이터, 스타일을 유지
- JSX가 길게 이어진 일부 반환식은 안전을 위해 원형 구조 유지

SCSS/CSS는 같은 스타일을 포함하도록 동기화했습니다.
실제 브라우저 검증 및 빌드 테스트는 수행하지 않았습니다.
