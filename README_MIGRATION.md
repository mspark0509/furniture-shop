# 인디박스 React + TypeScript 전환

## 실행
`npm install` → `npm run dev` → `npm run build`

## 구조
- `src/components`: 헤더(호버 서브메뉴, 검색 자동완성), 상품 카드/목록
- `src/pages`: 메인, 카테고리, 상세, 장바구니, 로그인
- `src/data`: 상품 93개 및 카테고리 JSON, 타입
- `src/styles`: 아이보리 & 브라운 테마
- `public/images`: 이전 V2에서 제공된 이미지 자료

## 기능
- PC 헤더 메뉴 호버 시 서브메뉴 노출 / 모바일 햄버거 메뉴
- 검색 추천어 6개, 입력 시 최대 10개 자동완성, Enter 시 전체 검색 결과
- 장바구니 수량/삭제 및 찜하기 로컬스토리지 보관
- 카테고리/서브카테고리, 24개씩 페이지네이션, 정렬
- 메인 추천 상품 일반 버튼형 가로 슬라이드
- 로그인은 UI만 구현, 실제 인증/결제 연동 없음

## 참고
기존 HTML 사이트와는 프로젝트 구조가 달라 전체 React 프로젝트를 제공함. 일부 상품명과 이미지는 시안용 데이터이며 실제 상품과 일치하지 않을 수 있음.
